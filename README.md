# Ochi Design – Animated Website Clone

A modern, animation-rich website inspired by Ochi Design, built using React, Tailwind CSS, and Framer Motion. The project focuses on smooth scroll interactions, marquee animations, hover-driven effects, and minimal UI inspired by award-winning design studios.

## 🚀 Features

Smooth scroll-based animations

Infinite marquee text animation

Hover-activated featured project titles

Scroll-aware navbar (hide on scroll down, show on scroll up)

Clean, responsive layout

Modern typography and color palette

## 🛠 Tech Stack

React (Vite)

Tailwind CSS

Framer Motion

React Icons

Locomotive Scroll (scroll-based effects)

3. Run the development server
npm run dev
